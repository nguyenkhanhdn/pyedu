5. Cấu trúc rẽ nhánh: if / else / elif / lồng nhau

Cho chương trình chọn đường đi theo điều kiện. Học theo 4 dạng từ dễ đến khó: if → if … else → if … elif … else → if lồng nhau. Nhớ dấu : cuối dòng và thụt lề 4 dấu cách.

DạngDùng khiCú pháp
1. ifChỉ làm thêm việc khi điều kiện đúng, sai thì bỏ quaif đk:
2. if … elseCó 2 trường hợp loại trừ nhau (đúng / sai)if đk: … else:
3. if … elif … elseCó nhiều trường hợp (3 trở lên)if … elif … else:
4. if lồng nhauĐiều kiện thứ hai chỉ xét sau khi điều kiện thứ nhất đã đúngif bên trong if
🔧 Bước 0 · Điều kiện là gì?

Điều kiện là biểu thức cho kết quả True (đúng) hoặc False (sai). Chương trình chỉ chạy khối lệnh của if khi điều kiện là True.

and or notVà / hoặc / phủ định3 > 1 and 2 > 5 → False

print(x == 3)
print(x % 2 == 0)           # x chia hết cho 2?
print(x > 5 and x < 20)     # cả hai cùng đúng

🔧 Dạng 1 · if — “Nếu … thì …”

Dạng đơn giản nhất: điều kiện đúng thì chạy khối lệnh thụt lề; điều kiện sai thì bỏ qua, chương trình đi tiếp xuống dưới.

  1. Tính điều kiện sau từ khóa if.
  2. True → chạy các dòng thụt vào dưới if.
  3. False → bỏ qua các dòng đó, chạy tiếp lệnh phía sau.

🔧 Dạng 3 · if … elif … else — nhiều trường hợp

Khi có từ 3 trường hợp trở lên, dùng elif (else if). Python kiểm tra từ trên xuống dưới; gặp điều kiện đúng đầu tiên thì chạy khối đó rồi bỏ qua toàn bộ phần còn lại.

  1. Xét if: đúng → chạy khối của nó và kết thúc cả chuỗi.
  2. Sai → xét elif thứ nhất, rồi thứ hai… cho đến khi gặp điều kiện đúng.
  3. Không điều kiện nào đúng → chạy khối else (nếu có). elif có thể viết bao nhiêu cái cũng được.

🔧 Dạng 4 · if lồng nhau — if trong if

Đặt một cấu trúc if bên trong khối lệnh của if khác (thụt lề thêm 4 dấu cách). Dùng khi một điều kiện chỉ có ý nghĩa sau khi điều kiện ngoài đã đúng. Mỗi tầng lồng thụt vào một cấp.

  1. Xét điều kiện ngoài trước. Sai → bỏ cả khối (kể cả if bên trong).
  2. Đúng → vào khối, rồi xét tiếp điều kiện trong.
  3. Mỗi cấp có thể có else/elif riêng — chú ý else thẳng hàng với if nào thì thuộc if đó.
Ví dụ 1 — Hai tầng: đủ tuổi rồi mới xét có thẻ
tuoi = 20
co_the = True
if tuoi >= 18:
    if co_the:
        print("Duoc vao")
    else:
        print("Can mang the")
else:
    print("Chua du tuoi")
▶ Kết quả
Duoc vao
Ví dụ 2 — Ba cạnh có tạo thành tam giác không, loại gì?
a, b, c = 3, 4, 5
if a + b > c and a + c > b and b + c > a:
    if a == b == c:
        print("Tam giac deu")
    elif a == b or b == c or a == c:
        print("Tam giac can")
    elif a * a + b * b == c * c:
        print("Tam giac vuong")
    else:
        print("Tam giac thuong")
else:
    print("Khong phai tam giac")
▶ Kết quả
Tam giac vuong
Ví dụ 3 — Giải phương trình ax + b = 0

    if b == 0:

    else:
        print("Vo nghiem")
▶ Kết quả
Vo nghiem
Ví dụ 4 — Đăng nhập hai bước: tên rồi mật khẩu

8. Vòng lặp lồng nhau

Đặt một vòng lặp bên trong vòng lặp khác: vòng ngoài chạy 1 lượt thì vòng trong chạy trọn vẹn một lần. Dùng để in hình, duyệt bảng/ma trận, thử mọi cặp giá trị.

🔧 Bước 1 · Ý tưởng: kim giờ và kim phút

Hãy hình dung đồng hồ: kim giờ (vòng ngoài) nhích 1 vạch thì kim phút (vòng trong) quay đủ một vòng. Tổng số lượt chạy của lệnh bên trong = số lượt vòng ngoài × số lượt vòng trong.

  1. Vòng ngoài lấy giá trị đầu tiên của i.
  2. Vòng trong chạy hết các giá trị j với i đó.
  3. Vòng ngoài sang giá trị tiếp theo của i, vòng trong bắt đầu lại từ đầu.
  4. Lặp đến khi vòng ngoài hết.
Ví dụ 1 — Quan sát thứ tự chạy
for i in range(1, 4):          # vòng ngoài: 3 lượt
    for j in range(1, 3):      # vòng trong: 2 lượt mỗi lần
        print("i =", i, "j =", j)

    if n < 2:
        return False

16. Đệ quy

Hàm tự gọi chính nó. Luôn cần điều kiện dừng (base case) và bước thu nhỏ bài toán.

Giai thừa
def giai_thua(n):
    if n <= 1:          # điều kiện dừng
        return 1
    return n * giai_thua(n - 1)

print(giai_thua(5))
▶ Kết quả

Tổng 1 đến n
def tong(n):
    if n == 1:
        return 1
    return n + tong(n - 1)

print(tong(10))
▶ Kết quả
55
Fibonacci
def fib(n):
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(1, 9)])
▶ Kết quả
[1, 1, 2, 3, 5, 8, 13, 21]
Tăng tốc đệ quy bằng bộ nhớ đệm
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)

print(fib(80))
▶ Kết quả

⚠️ Lưu ý: Thiếu điều kiện dừng → RecursionError. Python giới hạn ~1000 tầng; cần sâu hơn: sys.setrecursionlimit(10**6).

26. Số học: ước, UCLN, BCNN

Ước và bội, UCLN bằng thuật toán Euclid, đếm và liệt kê ước trong O(√N).

📖 Khái niệm & giải thích

Ước của n là số chia hết n (n % d == 0). UCLN(a, b) là ước chung lớn nhất; BCNN(a, b) là bội chung nhỏ nhất, tính nhanh bằng công thức a * b // UCLN.

Ước luôn đi theo cặp: nếu d là ước thì n // d cũng là ước. Vì vậy chỉ cần duyệt d từ 1 đến √n, không cần duyệt đến n.

🧩 Giải thuật Euclid (tìm UCLN)

Ý tưởng: UCLN(a, b) = UCLN(b, a % b). Cứ thay (a, b) bằng (b, a % b) cho đến khi b = 0, lúc đó a là UCLN.

  1. Khi b != 0: gán a, b = b, a % b.
  2. Khi b == 0: dừng, kết quả là a.
  3. BCNN = a * b // UCLN(a, b).
💻 Mã nguồn mẫu

def gcd(a, b):            # Euclid
    while b:
        a, b = b, a % b
    return a

def lcm(a, b):
    return a * b // gcd(a, b)

27. Số nguyên tố & phân tích thừa số

Kiểm tra nguyên tố trong O(√N), phân tích một số ra tích các thừa số nguyên tố.

📖 Khái niệm & giải thích

Số nguyên tố là số tự nhiên > 1 chỉ có đúng hai ước: 1 và chính nó (2, 3, 5, 7, 11…). Mọi số > 1 đều phân tích duy nhất thành tích các số nguyên tố, ví dụ 360 = 2 × 2 × 2 × 3 × 3 × 5.

Nếu n là hợp số thì nó có ước d thỏa 2 ≤ d ≤ √n. Do đó chỉ cần thử chia cho d đến √n.

🧩 Kiểm tra nguyên tố
  1. n < 2 → không phải số nguyên tố.
  2. Thử d = 2, 3, … trong khi d * d <= n; nếu có n % d == 0 → hợp số.
  3. Không tìm được ước nào → là số nguyên tố.
🧩 Phân tích thừa số nguyên tố
  1. Bắt đầu với d = 2.
  2. Khi d * d <= n: nếu n % d == 0 thì ghi nhận d và chia n //= d (lặp lại với cùng d); ngược lại tăng d.
  3. Kết thúc nếu n > 1 thì phần còn lại chính là một số nguyên tố, ghi nhận nốt.
💻 Mã nguồn mẫu

29. Sàng nguyên tố Eratosthenes

Tìm mọi số nguyên tố đến N trong O(N log log N) — nhanh hơn nhiều so với kiểm tra từng số.

📖 Khái niệm & giải thích

Kiểm tra từng số bằng O(√N) sẽ chậm khi cần cả danh sách nguyên tố đến N lớn (ví dụ 10⁶). Sàng Eratosthenes tận dụng một nhận xét: bội của một số nguyên tố chắc chắn là hợp số, nên ta gạch bỏ chúng hàng loạt.

🧩 Giải thuật (ý tưởng)
  1. Tạo mảng la_nt gồm N + 1 giá trị True; đặt la_nt[0] = la_nt[1] = False.
  2. Với mỗi p từ 2 đến √N: nếu la_nt[p] còn True thì p là nguyên tố.
  3. Gạch bỏ các bội của p bắt đầu từ p * p (các bội nhỏ hơn đã bị số nhỏ hơn gạch rồi): la_nt[p*p], la_nt[p*p+p], … = False.
  4. Cuối cùng, các chỉ số còn True chính là số nguyên tố.

def sieve(n):
    la_nt = [True] * (n + 1)

30. Quay lui (Backtracking) & sinh tổ hợp

Vét cạn thông minh: xây dựng lời giải từng bước, bỏ ngay nhánh chắc chắn sai rồi quay lại thử lựa chọn khác.

📖 Khái niệm & giải thích

Khi số lượng vòng lặp lồng nhau không cố định (ví dụ sinh mọi xâu nhị phân dài n), ta dùng đệ quy. Quay lui xây lời giải từng phần: chọn một giá trị cho vị trí hiện tại, đi tiếp vị trí sau; nếu bế tắc hoặc đã xong thì hủy lựa chọn (quay lui) để thử giá trị khác.

Khác vét cạn thuần túy ở chỗ: nếu lời giải *dở dang* đã vi phạm điều kiện thì dừng sớm (cắt tỉa), không đi tiếp nhánh đó.

🧩 Khung chung của quay lui
  1. Điều kiện dừng: lời giải đã đủ (len(cur) == n) → ghi nhận hoặc in ra.
  2. Thử từng lựa chọn cho vị trí hiện tại; bỏ qua lựa chọn vi phạm điều kiện (cắt tỉa).
  3. Chọn: đưa lựa chọn vào lời giải dở dang cur, gọi đệ quy cho vị trí kế tiếp.
  4. Bỏ chọn (quay lui): lấy lựa chọn đó ra khỏi cur (cur.pop()) để thử lựa chọn khác.

31. Sắp xếp

Hiểu cách các thuật toán sắp xếp cơ bản hoạt động; khi làm bài thật thì dùng sorted() / .sort() — O(N log N).

📖 Khái niệm & giải thích

Sắp xếp là đưa các phần tử về thứ tự tăng (hoặc giảm). Sắp xếp là bước tiền xử lý rất mạnh: dữ liệu có thứ tự thì tìm kiếm nhị phân, hai con trỏ, loại trùng… đều dễ dàng hơn.

32. Tìm kiếm tuần tự & nhị phân

Tìm một giá trị trong dãy: duyệt từng phần tử O(N) hoặc chia đôi dãy đã sắp xếp O(log N).

📖 Khái niệm & giải thích

Tìm kiếm tuần tự xem lần lượt từng phần tử — dùng được cho mọi dãy. Tìm kiếm nhị phân chỉ dùng cho dãy đã sắp xếp, nhưng mỗi bước loại bỏ một nửa dãy nên cực nhanh: 10⁹ phần tử chỉ cần ~30 bước.

  4. Hết vòng lặp mà chưa thấy → không có x (trả về -1).

33. Chia để trị & sắp xếp trộn

Chia bài toán thành các phần nhỏ hơn, độc lập, giải từng phần rồi gộp kết quả.

📖 Khái niệm & giải thích

Chia để trị (*divide and conquer*) gồm ba bước: Chia bài toán thành các bài con nhỏ hơn cùng dạng; Trị (giải) từng bài con, thường bằng đệ quy; Gộp các kết quả lại. Bài con nhỏ đến mức hiển nhiên thì dừng (trường hợp cơ sở).

Khác quy hoạch động: các bài con ở đây không gối nhau nên không cần lưu lại. Ví dụ tiêu biểu: tìm kiếm nhị phân, sắp xếp trộn O(N log N), lũy thừa nhanh O(log n).

🧩 Sắp xếp trộn (Merge Sort)
  1. Chia: cắt dãy làm hai nửa.
  2. Trị: sắp xếp mỗi nửa bằng chính thuật toán này (dãy 0 hoặc 1 phần tử thì đã xếp sẵn).
  3. Gộp: trộn hai nửa đã xếp thành một dãy xếp, bằng hai con trỏ — luôn lấy phần tử nhỏ hơn ở đầu hai nửa.
🧩 Lũy thừa nhanh

xⁿ = (xⁿ/²)² nếu n chẵn, xⁿ = x · xⁿ⁻¹ nếu n lẻ → chỉ cần O(log n) phép nhân thay vì n.

💻 Mã nguồn mẫu
Sắp xếp trộn — O(N log N)
def merge_sort(a):
    if len(a) <= 1:
        return a
    giua = len(a) // 2
    trai = merge_sort(a[:giua])
    phai = merge_sort(a[giua:])
    kq, i, j = [], 0, 0
    while i < len(trai) and j < len(phai):    # gộp hai nửa đã xếp

34. Mảng cộng dồn (Prefix sum)

Tính trước tổng tích lũy để trả lời mỗi truy vấn tổng đoạn trong O(1).

📖 Khái niệm & giải thích

Bài toán: cho mảng A và nhiều truy vấn “tổng các phần tử từ vị trí L đến R”. Cộng từng truy vấn mất O(N), với Q truy vấn là O(N·Q) — quá chậm.

Mảng cộng dồn pref[i] là tổng i phần tử đầu tiên. Khi đó tổng đoạn bằng hiệu hai mốc: pref[R+1] - pref[L].

🧩 Giải thuật (ý tưởng)
  1. Tạo pref có N + 1 phần tử, pref[0] = 0.
  2. Với i = 0..N-1: pref[i + 1] = pref[i] + A[i] — tiền xử lý O(N).
  3. Mỗi truy vấn (L, R) (chỉ số từ 0, gồm cả R): đáp án pref[R + 1] - pref[L] — chỉ O(1).

35. Hai con trỏ (Two pointers)

Dùng hai chỉ số cùng di chuyển để thay vòng lặp lồng O(N²) bằng một lượt duyệt O(N).

📖 Khái niệm & giải thích

Thay vì thử mọi cặp (i, j), ta giữ hai con trỏ và quyết định di chuyển con trỏ nào dựa trên kết quả hiện tại. Điều kiện để làm được: dãy có tính đơn điệu (thường là đã sắp xếp).

  • Hai đầu: một con trỏ ở đầu, một ở cuối, thu hẹp dần vào giữa.
  • Cửa sổ trượt: hai con trỏ cùng đi từ trái sang phải, giữ đoạn [l, r] thỏa điều kiện.
🧩 Tìm cặp có tổng bằng target (mảng đã sắp xếp)
  1. Đặt l ở đầu, r ở cuối.
  2. Tính s = a[l] + a[r]. Nếu s == target → xong.
  3. Nếu s < target → tổng quá nhỏ, tăng l (lấy số lớn hơn). Nếu s > target → giảm r.
  4. Lặp đến khi l >= r. Mỗi con trỏ chỉ đi một chiều nên tổng cộng O(N).
💻 Mã nguồn mẫu

def hai_so(a, target):
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target:
            return l, r
        elif s < target:
            l += 1
        else:
            r -= 1
    return None

37. Quy hoạch động cơ bản

Chia bài toán thành các bài con gối nhau, tính mỗi bài con một lần và lưu lại để dùng tiếp.

📖 Khái niệm & giải thích

Nhiều bài toán đệ quy bị chậm vì tính đi tính lại cùng một bài con (ví dụ Fibonacci đệ quy tốn O(2ᴺ)). Quy hoạch động (DP) giải mỗi bài con đúng một lần, lưu vào mảng dp, rồi dùng kết quả đó cho bài lớn hơn.

Hai điều kiện để dùng DP: (1) bài toán chia được thành bài con giống hệt dạng ban đầu; (2) các bài con gối nhau (cùng xuất hiện nhiều lần).

🧩 Quy trình 4 bước giải DP
  1. Định nghĩa trạng thái: dp[i] nghĩa là gì? (ví dụ: số tờ ít nhất để đổi i đồng).

  3. Điều kiện đầu (cơ sở): các giá trị nhỏ nhất đã biết (ví dụ dp[0] = 0).
  4. Thứ tự tính & đáp án: tính i tăng dần; đáp án là dp[n] hoặc max(dp).

39. Duyệt đồ thị: BFS & DFS

BFS (hàng đợi) tìm đường ngắn nhất theo số cạnh; DFS (đệ quy / ngăn xếp) đi sâu hết một nhánh.

📖 Khái niệm & giải thích

Đồ thị gồm các đỉnh (nút) và cạnh (đường nối). Ví dụ: bản đồ thành phố (đỉnh = ngã tư, cạnh = đường), mạng bạn bè, mê cung. Hai đỉnh nối trực tiếp với nhau gọi là kề.

Cách lưu phổ biến nhất là danh sách kề: với mỗi đỉnh u, lưu danh sách các đỉnh kề với u. Duyệt đồ thị là thăm mọi đỉnh đi tới được từ một đỉnh xuất phát, mỗi đỉnh đúng một lần (dùng tập da_tham để không lặp).

🧩 BFS — duyệt theo lớp (loang)

Giống vết dầu loang: thăm đỉnh xuất phát, rồi mọi đỉnh cách 1 cạnh, rồi cách 2 cạnh… nên BFS tìm được đường đi ngắn nhất theo số cạnh.

  1. Đưa đỉnh xuất phát vào hàng đợi q, đặt dist[start] = 0.
  2. Lấy đỉnh u ở đầu hàng đợi (popleft).
  3. Với mỗi đỉnh kề v chưa thăm: dist[v] = dist[u] + 1 và đưa v vào cuối hàng đợi.
  4. Lặp đến khi hàng đợi rỗng. Độ phức tạp O(V + E).
🧩 DFS — đi sâu hết nhánh

Đi theo một nhánh đến cùng, hết đường thì quay lui sang nhánh khác. Cài đặt tự nhiên bằng đệ quy.

  1. Đánh dấu đỉnh u đã thăm.
  2. Với mỗi đỉnh kề v chưa thăm: gọi dfs(v).
  3. Dùng để: kiểm tra liên thông, đếm thành phần liên thông, phát hiện chu trình, tìm đường trong mê cung.
💡 Mẹo: Cần đường ngắn nhất (số cạnh) → BFS. Cần duyệt/đếm/kiểm tra liên thông → DFS hoặc BFS đều được.

40. Xử lý xâu: đối xứng, đếm, mã hóa

Các bài toán xâu quen thuộc: palindrome, đảo từ, đếm tần suất, anagram, mã hóa Caesar.

📖 Khái niệm & giải thích

Xâu là dãy ký tự; hầu hết bài toán xâu quy về duyệt từng ký tự kết hợp dict/set, hoặc dùng phép cắt lát s[::-1]. Palindrome là xâu đọc xuôi và ngược giống nhau ("radar"). Hai xâu là anagram nếu cùng các chữ cái, chỉ khác thứ tự.

🧩 Giải thuật (ý tưởng)
  1. Đối xứng: chuẩn hóa (chữ thường, bỏ khoảng trắng) rồi so sánh s == s[::-1].
  2. Đếm tần suất: duyệt xâu, cộng dồn vào dict (hoặc Counter).
  3. Anagram: hai xâu có cùng bảng tần suất (hoặc cùng sorted).
  4. Caesar: dịch mỗi chữ cái đi k vị trí trong bảng 26 chữ, dùng phép % 26 để vòng lại.
💻 Mã nguồn mẫu

def caesar(s, k):
    kq = ""
    for c in s:
        if c.isalpha():
            goc = ord("A") if c.isupper() else ord("a")
            kq += chr((ord(c) - goc + k) % 26 + goc)   # % 26 để vòng lại
        else:
            kq += c
    return kq

m = caesar("Hello, World", 3)
print(m, caesar(m, -3))

🏆 Mẹo làm bài thi

  • Đọc nhanh: import sys; input = sys.stdin.readline.
  • Nhập list: a = list(map(int, input().split())).
  • In nhiều số một dòng: print(*a); in nhiều dòng: print("\n".join(map(str, a))).
  • Đệ quy sâu: sys.setrecursionlimit(10**6) hoặc đổi sang vòng lặp.
  • Kiểm tra thuộc nhiều lần → dùng set hoặc dict thay cho list (O(1) thay vì O(N)).
  • Sắp xếp rồi mới xử lý thường giúp giảm O(N²) xuống O(N log N).
  • Luôn thử các trường hợp biên: n = 0, n = 1, mảng 1 phần tử, số âm, tất cả bằng nhau.
