13. Bộ Thuật Toán Kinh Điển Ôn Thi Học Sinh Giỏi & Tin Học Trẻ

Các mẫu thuật toán được kiểm thử chuẩn mực: Sàng nguyên tố Eratosthenes, Tìm kiếm nhị phân, Mảng cộng dồn, Hai con trỏ và Quy hoạch động.

1. Sàng Nguyên Tố Eratosthenes (Tìm mọi số nguyên tố đến N trong O(N log log N))

SÀNG ERATOSTHENES CHUẨN 
def sieve_of_eratosthenes(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False
    for p in range(2, int(limit**0.5) + 1):
        if is_prime[p]:
            for multiple in range(p * p, limit + 1, p):
                is_prime[multiple] = False
    return [i for i, prime in enumerate(is_prime) if prime]

2. Tìm Kiếm Nhị Phân (Binary Search - O(log N))

TÌM KIẾM NHỊ PHÂN TRÊN MẢNG ĐÃ SẮP XẾP 
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid # Trả về vị trí tìm thấy
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1 # Không tìm thấy

3. Mảng Cộng Dồn (Prefix Sum - Tính tổng đoạn [L, R] trong O(1))

MẢNG CỘNG DỒN PREFIX SUM 
# Cho mảng A gồm N số, tính tổng A[L..R] cho Q truy vấn
A = [2, 4, 1, 7, 5, 3]
n = len(A)

# Xây dựng prefix sum: pref[i] là tổng từ A[0] đến A[i-1]
pref = [0] * (n + 1)
for i in range(n):
    pref[i + 1] = pref[i] + A[i]

# Truy vấn tổng từ vị trí L đến R (chỉ số 0-based) trong O(1):
def query_sum(L, R):
    return pref[R + 1] - pref[L]

4. Kỹ Thuật Hai Con Trỏ (Two Pointers - Bài toán Two Sum trên mảng đã sort)

HAI CON TRỎ O(N) 
def two_sum_sorted(arr, target):
    left = 0
    right = len(arr) - 1
    while left < right:
        curr_sum = arr[left] + arr[right]
        if curr_sum == target:
            return left, right
        elif curr_sum < target:
            left += 1
        else:
            right -= 1
    return None

Tên lỗi (Exception) Nguyên nhân gốc rễ Cách giải quyết
IndexError: list index out of range Truy cập chỉ số vượt quá độ dài mảng (vd mảng có 5 phần tử nhưng gọi a[5]) Kiểm tra điều kiện 0 <= i < len(a) hoặc dùng len(a) - 1.
TypeError: can only concatenate str to str Cố tình dùng phép + giữa chuỗi và số nguyên mà chưa ép kiểu Ép kiểu sang str() hoặc dùng f-string: f"{text}{number}".
KeyError: '...' Truy cập khóa không tồn tại trong Dictionary Dùng phương thức an toàn dict.get(key, default).
ZeroDivisionError: division by zero Chia cho 0 trong phép /, // hoặc % Thêm kiểm tra if b != 0: trước khi thực hiện phép chia.
IndentationError Thụt lề không đều hoặc trộn lẫn giữa phím Tab và phím Space Chuyển toàn bộ thụt dòng sang 4 phím dấu cách (Space).
RecursionError: maximum recursion depth exceeded Đệ quy không có điểm dừng (Base case) hoặc sâu quá 1000 lần Bổ sung điều kiện dừng hoặc dùng sys.setrecursionlimit(10**6).
Time Limit Exceeded (TLE) Độ phức tạp thuật toán quá lớn (vd O(N^2) với N = 10^5) Tối ưu sang O(N log N) hoặc O(N), dùng sys.stdin.readline.
