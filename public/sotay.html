1. Chương trình đầu tiên & lệnh print

print() hiển thị ra màn hình. Dòng bắt đầu bằng # là chú thích, Python bỏ qua.

In lời chào
# Đây là chú thích
print("Xin chao Python!")
print("Dong 2")
▶ Kết quả
Xin chao Python!
Dong 2
In nhiều giá trị: sep và end
print(2026, 9, 5, sep="/")        # sep: ký tự ngăn cách
print("Xin", end=" ")             # end: ký tự cuối (mặc định xuống dòng)
print("chao")
▶ Kết quả
2026/9/5
Xin chao
f-string: chèn biến vào chuỗi
ten = "An"
tuoi = 16
print(f"{ten} {tuoi} tuoi")
print(f"Sau 5 nam: {tuoi + 5} tuoi")
▶ Kết quả
An 16 tuoi
Sau 5 nam: 21 tuoi
💡 Mẹo: Chuỗi đặt trong "..." hoặc '...' đều được. Muốn xuống dòng trong chuỗi dùng \n.

5. Rẽ nhánh if / elif / else

Chạy khối lệnh tùy theo điều kiện. Nhớ dấu : cuối dòng và thụt lề 4 dấu cách.

n = 7

    print("So chan")
else:
    print("So le")
▶ Kết quả
So le
Nhiều trường hợp: if ... elif ... else
diem = 7.2
if diem >= 8:
    print("Gioi")
elif diem >= 6.5:
    print("Kha")
elif diem >= 5:
    print("Trung binh")
else:
    print("Yeu")
▶ Kết quả
Kha
Kết hợp điều kiện: and / or / not
tuoi = 16
if tuoi >= 15 and tuoi <= 18:
    print("THPT")
thu = "CN"
if thu == "T7" or thu == "CN":
    print("Nghi hoc")
▶ Kết quả
THPT
Nghi hoc
Viết gọn
diem = 6
kq = "Do" if diem >= 5 else "Truot"   # toán tử ba ngôi
print(kq)
print(0 <= diem <= 10)               # so sánh kép
▶ Kết quả
Do
True
⚠️ Lưu ý: Lỗi hay gặp: quên : cuối dòng if/elif/else; thụt lề không đều; dùng = (gán) thay cho == (so sánh).
💡 Mẹo: Thứ tự elif quan trọng: điều kiện đầu tiên đúng sẽ chạy, các nhánh sau bị bỏ qua.

7. Vòng lặp while, break, continue

while lặp khi điều kiện còn đúng. break thoát hẳn; continue bỏ qua lượt hiện tại.

while cơ bản
i = 1
while i <= 5:
    print(i, end=" ")
    i += 1          # nhớ tăng biến để không lặp vô hạn
print()
▶ Kết quả
1 2 3 4 5
Tổng chữ số của một số
n = 12345
tong = 0
while n > 0:
    tong += n % 10
    n //= 10
print(tong)
▶ Kết quả
15
break và continue
for i in range(1, 10):
    if i == 3:
        continue     # bỏ qua số 3
    if i == 6:
        break        # dừng khi gặp 6
    print(i, end=" ")
print()
▶ Kết quả
1 2 4 5
Nhập lại cho đến khi hợp lệ
while True:
    n = int(input())
    if 1 <= n <= 20:
        break
print("Hop le:", n)
Nhập vào:
50
-3
7
▶ Kết quả
Hop le: 7
for ... else: else chạy khi vòng lặp KHÔNG bị break
n = 29
for d in range(2, int(n ** 0.5) + 1):
    if n % d == 0:
        print(n, "la hop so")
        break
else:
    print(n, "la so nguyen to")
▶ Kết quả
29 la so nguyen to
⚠️ Lưu ý: while không thay đổi biến điều kiện sẽ lặp vô hạn. Dùng Ctrl + C để dừng.

8. Chuỗi (str)

Chuỗi là dãy ký tự không thể sửa tại chỗ. Chỉ số bắt đầu từ 0; chỉ số âm đếm từ cuối.

Chỉ số và độ dài
s = "Python"
print(len(s))      # 6
print(s[0], s[-1])  # P n
▶ Kết quả
6
P n
Cắt lát s[start:stop:step]
s = "0123456789"
print(s[:4])      # 0123 (4 ký tự đầu)
print(s[-3:])     # 789 (3 ký tự cuối)
print(s[2:6])     # 2345
print(s[::2])     # 02468 (bước 2)
print(s[::-1])    # đảo ngược chuỗi
▶ Kết quả
0123
789
2345
02468
9876543210
Phương thứcTác dụngVí dụ → kết quả
.strip()Xóa khoảng trắng hai đầu" a ".strip() → "a"
.lower() .upper()Chữ thường / HOA"Ab".upper() → "AB"
.title() .capitalize()Hoa chữ đầu mỗi từ / chữ đầu"an binh".title() → "An Binh"
.split()Tách thành list các từ"a b".split() → ['a', 'b']
"-".join(list)Nối list thành chuỗi"-".join(['a','b']) → "a-b"
.replace(a, b)Thay a bằng b"aab".replace("a","x") → "xxb"
.find(x)Vị trí đầu tiên (không thấy: -1)"hello".find("l") → 2
.count(x)Đếm số lần xuất hiện"banana".count("a") → 3
.startswith(x) .endswith(x)Bắt đầu / kết thúc bằng x"abc".startswith("a") → True
.isdigit() .isalpha()Toàn chữ số / toàn chữ cái"123".isdigit() → True
Chuẩn hóa họ tên

print(" ".join(w.capitalize() for w in ten.split()))

Kiểm tra chuỗi đối xứng (Palindrome)

Duyệt từng ký tự và đếm

9. Danh sách (list)

List là dãy có thứ tự, sửa được, chứa nhiều kiểu dữ liệu. Cắt lát giống chuỗi.

Tạo, truy cập, sửa
a = [5, 2, 9, 1]
print(a[0], a[-1], len(a))
a[1] = 99
print(a)
print(a[1:3])
▶ Kết quả
5 1 4
[5, 99, 9, 1]
[99, 9]
Phương thứcTác dụngĐộ phức tạp
.append(x)Thêm x vào cuốiO(1)
.insert(i, x)Chèn x vào vị trí iO(N)
.pop() / .pop(i)Xóa & trả về phần tử cuối / tại iO(1) / O(N)
.remove(x)Xóa phần tử x đầu tiênO(N)
.index(x)Vị trí của x (không có: báo lỗi)O(N)
.count(x)Đếm số lần x xuất hiệnO(N)
.sort()Sắp xếp tại chỗO(N log N)
.reverse()Đảo ngược tại chỗO(N)
sorted(a)Trả về list mới đã sắp xếpO(N log N)
Thêm, xóa
a = [1, 2, 3]
a.append(4)
a.insert(0, 0)
print(a)
a.remove(2)
last = a.pop()
print(a, last)
▶ Kết quả
[0, 1, 2, 3, 4]
[0, 1, 3] 4
Hàm thống kê có sẵn
a = [5, 2, 9, 1, 5]
print(len(a), sum(a), min(a), max(a))
print(5 in a, a.count(5))
▶ Kết quả
5 22 1 9
True 2
Sắp xếp
a = [5, 2, 9, 1]
print(sorted(a))                 # tăng dần, a không đổi
print(sorted(a, reverse=True))   # giảm dần
a.sort()
print(a)
▶ Kết quả
[1, 2, 5, 9]
[9, 5, 2, 1]
[1, 2, 5, 9]
Sắp xếp theo tiêu chí riêng (key)
ten = ["binh", "an", "cuong"]
ten.sort(key=len)               # theo độ dài
print(ten)
▶ Kết quả
['an', 'binh', 'cuong']
Danh sách 2 chiều (ma trận)
m = [[1, 2, 3], [4, 5, 6]]
print(m[1][2])        # hàng 1, cột 2
for hang in m:
    print(*hang)
m0 = [[0] * 3 for _ in range(2)]   # ma trận 2x3 toàn số 0
print(m0)
▶ Kết quả
6
1 2 3
4 5 6
[[0, 0, 0], [0, 0, 0]]
⚠️ Lưu ý: Sao chép list: b = a không tạo bản sao (cùng một danh sách). Dùng b = a.copy() hoặc b = a[:].
⚠️ Lưu ý: Ma trận: không viết [[0] * 3] * 2 (các hàng dùng chung). Hãy dùng [[0] * 3 for _ in range(2)].
Cấp 2

10. Tuple & Set

Tuple ( ) là bộ bất biến. Set { } là tập hợp không trùng lặp, kiểm tra in rất nhanh O(1).

Tuple: đóng gói, giải nén
p = (10, 20)
x, y = p
print(x, y, p[0])
# p[0] = 5   # lỗi: tuple không sửa được
▶ Kết quả
10 20 10
Set: loại phần tử trùng
ids = [101, 102, 101, 103, 102]
print(set(ids))
print(len(set(ids)))        # số phần tử khác nhau
▶ Kết quả
{101, 102, 103}
3
Phép toán tập hợp
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
print(A | B)   # hợp
print(A & B)   # giao
print(A - B)   # hiệu
print(A ^ B)   # hiệu đối xứng
▶ Kết quả
{1, 2, 3, 4, 5, 6}
{3, 4}
{1, 2}
{1, 2, 5, 6}
Thêm, xóa, kiểm tra
s = {1, 2}
s.add(3)
s.discard(1)
print(s, 3 in s)
▶ Kết quả
{2, 3} True
💡 Mẹo: Set không có thứ tự nên không có chỉ số s[0]. Cần đếm số phần tử khác nhau → dùng len(set(a)).
Cấp 2

11. Từ điển (dict)

Lưu cặp khóa → giá trị. Tra cứu theo khóa rất nhanh O(1).

Tạo và truy cập
sv = {"ten": "An", "tuoi": 16}
print(sv["ten"])
sv["lop"] = "10A1"     # thêm / sửa
print(sv)
▶ Kết quả
An
{'ten': 'An', 'tuoi': 16, 'lop': '10A1'}
Cú phápTác dụng
d[k]Lấy giá trị (không có khóa: KeyError)
d.get(k, mac_dinh)Lấy giá trị an toàn
k in dKiểm tra khóa có tồn tại
d.keys() d.values() d.items()Các khóa / giá trị / cặp (khóa, giá trị)
d.pop(k)Xóa khóa và trả về giá trị
del d[k]Xóa khóa
Duyệt key, value
d = {"a": 1, "b": 2}
for k, v in d.items():
    print(k, v)
▶ Kết quả
a 1
b 2
Đếm tần suất xuất hiện
arr = ["cam", "tao", "cam", "le", "tao", "cam"]
dem = {}
for x in arr:

def binary_search(a, x):
    l, r = 0, len(a) - 1
    while l <= r:
        m = (l + r) // 2
        if a[m] == x:
            return m
        elif a[m] < x:
            l = m + 1
        else:
            r = m - 1
    return -1

22. Sàng nguyên tố Eratosthenes

Tìm mọi số nguyên tố đến N trong O(N log log N) — nhanh hơn nhiều so với kiểm tra từng số.

Sàng đến N
def sieve(n):
    la_nt = [True] * (n + 1)
    la_nt[0] = la_nt[1] = False
    for p in range(2, int(n ** 0.5) + 1):
        if la_nt[p]:
            for boi in range(p * p, n + 1, p):
                la_nt[boi] = False
    return [i for i in range(n + 1) if la_nt[i]]

print(sieve(50))

for i in range(len(A)):
    pref[i + 1] = pref[i] + A[i]

def tong(L, R):          # chỉ số tính từ 0, gồm cả R
    return pref[R + 1] - pref[L]

def hai_so(a, target):
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target:
            return l, r
        elif s < target:
            l += 1
        else:
            r -= 1
    return None

🛠️ Lỗi thường gặp & cách sửa

Đọc tên lỗi ở dòng cuối của thông báo, đối chiếu bảng dưới đây.

🏆 Mẹo làm bài thi

  • Đọc nhanh: import sys; input = sys.stdin.readline.
  • Nhập list: a = list(map(int, input().split())).
  • In nhiều số một dòng: print(*a); in nhiều dòng: print("\n".join(map(str, a))).
  • Đệ quy sâu: sys.setrecursionlimit(10**6) hoặc đổi sang vòng lặp.
  • Kiểm tra thuộc nhiều lần → dùng set hoặc dict thay cho list (O(1) thay vì O(N)).
  • Sắp xếp rồi mới xử lý thường giúp giảm O(N²) xuống O(N log N).
  • Luôn thử các trường hợp biên: n = 0, n = 1, mảng 1 phần tử, số âm, tất cả bằng nhau.
